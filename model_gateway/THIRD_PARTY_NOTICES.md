# Third-party reference attribution

Sturgis Model Gateway is an independent Python subsystem. Its architecture audit
and native provider protocol implementations were informed by the public
[9router source](https://github.com/decolua/9router) at commit
`17c4cc76877bd1755030a8414f8d0083f48dcccf` (package version 0.5.75).
The 9router JavaScript engine is not embedded, launched, or required by this
package. Public OAuth client identifiers and installed-application configuration
are protocol configuration, not imported user account credentials.
