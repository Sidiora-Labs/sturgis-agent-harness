# Bundled dependency notices

The npm tarball for `react-remove-scroll-bar@2.3.8` omits its MIT license text.
`react-remove-scroll-bar.LICENSE` is an unmodified copy retrieved on 2026-09-12
from https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/master/LICENSE.
The Vite build uses this version-specific copy when assembling third-party
notices in the portable client. All other library and font notices come from
their pinned installed packages. The qualification manifest hashes this copy.
